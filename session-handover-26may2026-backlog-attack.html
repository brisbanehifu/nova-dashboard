R5 — Mobile bottom nav not sticky on scroll UX

Symptom: On iOS Chrome (and possibly Android Chrome), the bottom tab bar (Services / Bookings / Contacts / Ask NEO / More) detaches from the viewport bottom and floats mid-page during scroll.

Likely root cause: classic position: fixed + 100vh interaction with iOS browser-chrome collapse. Visible viewport changes when the address bar hides, but vh is locked to the large viewport.

Likely fix family:

position: fixed;
bottom: 0;
height: calc(100dvh - --header);     /* dvh not vh — dynamic viewport */
padding-bottom: env(safe-area-inset-bottom);   /* iPhone notch / home indicator */
-webkit-overflow-scrolling: touch;

Files likely touched: frontend/src/components/lg/BottomTabBar.tsx + its CSS / Tailwind classes.

🚧 Verify before claiming fixed:

  • Desktop unchanged ✓
