Every Monday 60 min: [ ] GBP Post published (rotate offer / educational / event / before-after) [ ] GBP Q&A monitored — answer any new questions within 24h [ ] Google review velocity check — target 2-3 new this week from BAT workflow [ ] HARO + SourceBottle daily filter (cumulative effort tracked) [ ] 1 new cluster post published (Phase 3 ongoing) [ ] GSC Performance report — note any new top-10 queries [ ] PageSpeed Insights spot-check on 1 random page [ ] Microsoft Clarity — watch 5 random sessions, note any new friction
⬜ 7.2 Monthly cadence (3 hr) 3 hr/month ▼
First Monday of each month: [ ] GSC vs prior-month: organic clicks, impressions, avg position, indexed pages — log to dashboard [ ] GA4 vs prior-month: sessions, conversion rate, top landing pages, top exit pages [ ] Backlink count via Ahrefs/Moz: new referring domains, lost domains, DA-30+ acquisitions [ ] Google Ads vs prior-month: CTR, CPC, conversions, cost-per-conversion [ ] Net new Google reviews + average rating [ ] Phase status update: what % of each phase complete [ ] 1 internal-link sweep across all published pages (10 min) [ ] 1 stale-content refresh (oldest pillar or cluster) [ ] 1 competitor SERP check on top 5 commercial queries
⬜ 7.3 Quarterly cadence (8 hr) 8 hr/quarter ▼
End of each quarter (every 3 months): [ ] Full SEO audit using Screaming Frog (free up to 500 URLs) — fix any new 404s, redirect chains, missing meta, large images [ ] Schema validator sweep on all 12 schema node types — fix any deprecation warnings [ ] Content refresh: pick 5 oldest pillars, update with new data + reviewed date [ ] Backlink prune: identify any new toxic backlinks via Moz Spam Score, disavow if needed [ ] Competitor gap analysis: identify 3 keywords competitors rank for that you don't, queue content to cover [ ] KPI review vs Phase 1 targets — what's tracking, what's lagging [ ] Quarterly business report for Kim (1-page) — organic clicks, conversions, leads, ROI vs other channels
