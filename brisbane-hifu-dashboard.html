8Standing rules — read before editing

🚨 Brisbane HIFU is on LOVABLE, not Hostinger. Hostinger is DNS-only since 15 May 2026 cutover. Banners / new pages / copy edits / SEO meta → Lovable editor. NEVER advise editing the website via Hostinger's website builder (it's empty — Zyro was deleted). DNS records (A/CNAME/TXT) DO still live in Hostinger DNS panel.
⚖ ACL + brand rules:
1. Never invent regulatory claims (TGA-registered, FDA-cleared, medical-grade, clinically proven) unless Kim has confirmed it's true for the SPECIFIC device.
2. Never write "Patient" — always "Client" (cosmetic context, not medical).
3. Schema is BeautySalon, not MedicalBusiness — locked per non-medical positioning.
4. Never use anchor pricing like "$1,700 normally $3,400" — ACL s.29 risk (already cleaned up).
5. Never write "results guaranteed" or similar express warranty — ACL s.29 risk.
🏆 Brisbane vs Redlands competitive separation: Brisbane HIFU's keyword lists, ad strategies, bid tactics, and audience layers are NEVER replicated into Redlands HIFU. Quality delta intentional. For policy appeals, draft generic AU-practitioner justifications — never cite Brisbane HIFU as precedent.
📷 Media substitution rule: When prompting Lovable / AI builders for media, NEVER allow them to substitute their own Pexels/stock/AI media when extraction fails. Spec says "if extraction fails, leave the slot blank, label EXTRACTION FAILED, ask me what to do."
🔍 Verification rule: For Lovable page rebuilds, verify page structure with Claude-in-Chrome MCP, NOT WebFetch alone. WebFetch has confabulated structure twice on Brisbane HIFU rebuilds (deals page count, blog index emptiness).
