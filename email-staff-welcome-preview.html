What I need from you (Canva)

If you're up for designing a header:
  • Size: 600 × 200 px PNG (most email clients cap at 600 wide)
  • One per "brand": Brisbane HIFU has its own; BookATreatment.AI (for tenant signup + nurture series) has its own. Or one generic that works for both — your call.
  • Content: Logo + clinic name + maybe a tagline. Keep type large enough to read on mobile (no fine print — mobile email clients shrink images).
  • Format: PNG with white or transparent background, < 100 KB so it loads instantly. JPEG is fine for photo-heavy designs.
  • Hosting: Send me the file → I host on the same GitHub Pages repo as the migration checklist (free, instant, HTTPS) → I wire the URL into the email template once.
  • Reusable: Same image goes on staff welcome + all Path C emails. Saves duplicating design work.

Once you send me the PNG (or two — one for clinics, one for BAT), I add it to the template and every email built from this point forward picks it up automatically. No additional dev cost per email.
