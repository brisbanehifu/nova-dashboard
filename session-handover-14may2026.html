Bug discovered 14 May PM during visual UI sweep. Live PROD, Brisbane HIFU tenant.

DOM state is correct:

  • data-theme="light" set on <html>

Components ignore the theme: sidebar / PageHeader card / booking row cards / calendar event cards / calendar today-column highlight all stay dark. Many hard-coded bg-[#221240] / bg-purple-900 style classes don't have dark: + light variants.
